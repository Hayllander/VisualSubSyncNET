### What changed

- **Drag and drop files onto the main window.** Dropping a `.vssprj` opens the project (asking to save pending changes first, like Open Project). Dropping a video and/or subtitle (also `.wav` or `.peak`) opens **New Project** already filled in; a second subtitle becomes the VO subtitle. This is new in this version, the original VisualSubSync didn't support it.
