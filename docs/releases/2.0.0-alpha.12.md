## VisualSubSyncNET 2.0.0-alpha.12 (pre-release)

### Highlights

- **Enhanced plugins:** Error checking now ships the VisualSubSync Enhanced JavaScript plugins, so the right-click **Fix** works again.
- **Audio sync** (new, VisualSubSyncNET only): reports subtitles that start too early or too late compared with the voice in the waveform. Report only, no Fix.
- **Line balance** (new, VisualSubSyncNET only): finds two-line subtitles that fit in one line or are badly split (like "da / frente") and rebreaks them on **Fix**.

### Error report improvements

- After a fix, the status bar shows how many errors are left, and the main window stays on the subtitle you were working on.
- **Clear & Forget** is enabled (also on the **Del** key). Forgotten errors are saved in the project, like in Enhanced.
- "Clear all errors with the same / different message" are enabled.

### Plugin API

- New functions: `GetPluginParamValue`, `DeleteSubtitle`, `GetAudioLevel`, `FindAudio` (see `jsplugin/readme.txt`).

### Install

Download `VisualSubSyncNET-2.0.0-alpha.12-Setup.exe` and run it. The installer removes the old 1.0.1-only plugins.
