### What changed

- Subtitle list right-click menu, **Other styles**: the position items (**Text to top left** ... **Text to middle right**) and the case items (**lowercase**, **UPPERCASE**, **Capitalize every word**) are now enabled and work like in VisualSubSync Enhanced. Positions insert `{\an1}`..`{\an9}` in SRT files; case changes keep the tags.
- The hotkeys for the position actions (Preferences → Hotkeys) now work too.
