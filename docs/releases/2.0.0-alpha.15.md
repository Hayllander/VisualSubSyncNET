### What changed

- Subtitle list right-click menu: new **Text in uppercase** item, right below **Text in italic**, with the **Ctrl+U** shortcut. It changes the selected subtitles to uppercase and keeps the tags, in a single undo step. The shortcut can be changed in Preferences → Hotkeys.
